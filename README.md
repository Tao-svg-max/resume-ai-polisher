# AI 简历抛光机

本项目是一个基于 Streamlit 的交互式应用，为用户（主要为中国大学生）提供基于大模型的简历润色服务，支持多轮对话、结构化反馈及多类型文档上传。

## 功能亮点

- **简历润色与优化**：应用大模型（Qwen-plus），模拟大厂资深技术面试官对简历进行点评、润色与结构化建议，严格遵循 STAR 法则，并面向目标岗位个性化输出。
- **多方式输入**：支持 PDF 与 DOCX 简历上传自动解析/提取文本，也可以直接输入原始项目描述内容。
- **多轮交互**：用户可根据结果继续提出修改、语言转化等意见，应用会基于全部历史对话智能地进行响应，实现持续优化。
- **使用便捷**：参数可选、交互友好，适合求职学生自助使用。

## 使用方法

1. 在左侧栏设置目标岗位及润色重点。
2. 上传 PDF 或 DOCX 格式的简历，或手动粘贴待润色内容。
3. 点击“开始智能润色”按钮，等待 AI 响应。
4. 查看润色结果，如有需要可在下方继续提修改意见。
5. 点击“清空对话历史”按钮可重新开始。

## 配置说明

1. 配置 `.streamlit/secrets.toml` 文件，设置 `DASHSCOPE_API_KEY` 字段以调用阿里云 DashScope 大模型 API。
2. 若无 API Key，应用将无法正确调用模型接口并返回结果。

## 主要依赖

- streamlit
- requests
- pypdf
- docx

## 部署与运行

```bash
pip install streamlit pypdf python-docx requests
streamlit run app.py
```

## 适用场景

- 校园招聘、实习岗位、技术求职者简历润色
- 多轮 AI 智能修改建议、结构化优化
